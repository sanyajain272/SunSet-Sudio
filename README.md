#  Sunset Studio

A modern and visually engaging portfolio website inspired by creative studio designs. This project showcases smooth animations, responsive layout, and an interactive user experience.

##  Live Demo

🔗 https://sun-down-studio-gamma.vercel.app/

##  Features

* Smooth scrolling animations
* Interactive navigation menu
* Responsive design (mobile + desktop)
* Modern UI/UX layout
* Contact section for user interaction

##  Tech Stack

* HTML5
* CSS3
* JavaScript
* Locomotive Scroll
* Swiper.js

##  Project Structure

```
Sunset-Studio/
│── index.html
│── style.css
│── script.js
│── video.mp4
```

##  How to Run Locally

1. Clone the repository

```
git clone https://github.com/sanyajain272/SunSet-Sudio.git
```

2. Open folder in VS Code
3. Run with Live Server

##  Customization

* Update text/content in `index.html`
* Modify styles in `style.css`
* Add animations in `script.js`
